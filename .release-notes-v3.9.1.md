## snapgentV3 V3.9.1

This patch release fixes the MCP target dropdown on the chat bar: it could not be clicked reliably, and a server that was switched back on did not reappear.

### Fixed
- **Target dropdown not clickable.** The target menu is no longer rewritten when its contents have not changed. Periodic status updates used to redraw the buttons between mouse-down and mouse-up, so the click never fired.
- **Re-enabled MCP server missing from the dropdown.** Toggling a server in the **MCP servers** panel now refreshes the target dropdown immediately, without waiting for the panel to close.

### Documentation
- Added troubleshooting rows to `README.md` for a missing MCP server in the target dropdown and for dropdown clicks that do nothing.
- Added a Discord invite link to the `README.md` header.
- The release badge, install link and footer in `README.md` now point to V3.9.1.

### Changed
- Extension version bumped to **3.9.1**.

### Upgrade
Pull the latest `main`, reload the extension at `chrome://extensions` (or `edge://extensions`), then refresh open chat tabs (F5). The bridge does not need to change.

Full history: see [CHANGELOG.md](https://github.com/herdodp/snapgent-connector/blob/main/CHANGELOG.md).
