## snapgentV3 V3.9.10

This release adds a Microsoft Word MCP server to the setup scripts. Word `.docx` files can now be created, read and edited from the chat bar target selector. The bridge is unchanged (still 3.9.7), so `bridge.exe` does not need to be rebuilt.

### Added
- **Word MCP server (`word`).** `setup-config.ps1` (Windows) and `setup-config.py` (macOS/Linux) now detect `uvx` and register the `office-word-mcp-server` package in `config.json`. After you restart the bridge, `word` appears in the MCP servers panel and in the target selector. It works on `.docx` files on disk and does not need Microsoft Word to be installed. Close a document in Word before the AI edits it, because Word locks open files.
- If `uv` is not installed, the setup scripts print an install hint (https://docs.astral.sh/uv/) and the other servers stay available.

### Changed
- Extension and Snapgent App versions bumped to **3.9.10**.

### Upgrade
Reload the extension at `chrome://extensions` (or `edge://extensions`) and refresh open chat tabs (F5) so the popup shows `ext v3.9.10`. Run the start script (or the setup script) once so the `word` server is added to `config.json`, then restart the bridge. The first start of `word` downloads its Python packages, so it can take a minute and needs internet once.

The attached zip contains everything needed to run: the extension, `bridge.exe`, `vscode_mcp.exe`, the start scripts (`start.bat`, `MacOS_Start.command`, `Linux_Start.sh`), the setup scripts, the Python sources and the README. Extract it, load the `snapgent-extension` folder, and run the start script for your system.
