## snapgentV3 V3.9.10

This release adds a Microsoft Word MCP server to the setup scripts. Word `.docx` files can now be created, read and edited from the chat bar target selector. The bridge is unchanged (still 3.9.7), so `bridge.exe` does not need to be rebuilt.

### Added
- **Word MCP server (`word`).** `setup-config.ps1` (Windows) and `setup-config.py` (macOS/Linux) now detect `uvx` and register the `office-word-mcp-server` package in `config.json`. After you restart the bridge, `word` appears in the MCP servers panel and in the target selector. It works on `.docx` files on disk and does not need Microsoft Word to be installed. Close a document in Word before the AI edits it, because Word locks open files.
- If `uv` is not installed, the setup scripts print an install hint (https://docs.astral.sh/uv/) and the other servers stay available.

### Changed
- Extension and Snapgent App versions bumped to **3.9.10**.

### Word target: requirements and usage
The **Word** target works differently from VS Code. It does not follow the open VS Code workspace and does not need Microsoft Word to be installed.

**Requirements**
- `uv` installed, so that `uvx` is available (https://docs.astral.sh/uv/).
- Internet access on the first run, because `uvx` downloads `office-word-mcp-server` when it is first used.
- Start the bridge with the normal launcher (`start.bat`, `MacOS_Start.command` or `Linux_Start.sh`) after `uv` is installed. If you install `uv` later, close the launcher and start it again.

**How to use**
1. Install `uv`, then start the launcher. Look for `Word MCP detected (uvx)` in its output.
2. Open a supported AI chat site, start a new chat and click **Start**.
3. In the **MCP target** selector on the chat bar, choose **Word**. If it is not listed, open **MCP servers** from the three-dots (...) menu on the snapgent bar and tick `word`, then reload the extension and refresh the chat tab.
4. Describe the document you want, for example: "Create a report in `D:\Documents\report.docx` with a title, three headings and a table." If you give only a file name (for example `report.docx`), the file is created inside the main Snapgent folder, the same folder that contains `start.bat`, `bridge.exe` and `config.json`. To save it somewhere else, give the full path.
5. To work on code again, switch the target back to **VS Code**.

**First run:** the first time you use the Word target, `uvx` downloads `office-word-mcp-server` and its dependencies. Wait until the download finishes before sending more requests, and watch the progress in the bridge console (the terminal window running the launcher). If the Word target seems stuck, check that console first.

### Upgrade
Reload the extension at `chrome://extensions` (or `edge://extensions`) and refresh open chat tabs (F5) so the popup shows `ext v3.9.10`. Run the start script (or the setup script) once so the `word` server is added to `config.json`, then restart the bridge. The first start of `word` downloads its Python packages, so it can take a minute and needs internet once.

The attached zip contains everything needed to run: the extension, `bridge.exe`, `vscode_mcp.exe`, the start scripts (`start.bat`, `MacOS_Start.command`, `Linux_Start.sh`), the setup scripts, the Python sources and the README. Extract it, load the `snapgent-extension` folder, and run the start script for your system.
