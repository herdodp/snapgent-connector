## snapgentV3 V3.9.11

This release adds a **Skills** section to the Switch AI menu, with a bundled **Antislop** skill that you can turn on or off. Antislop helps the AI write text that reads naturally in Word and generate code and website designs that do not look like generic AI output. The bridge is unchanged (still 3.9.7), so `bridge.exe` does not need to be rebuilt.

### Added
- **Skills section in the Switch AI menu.** It sits below the AI grid. The first row is the bundled **Antislop** toggle. Skills in `.snapgent/skills/` (for example `commit-message` and any skill you import) appear in the same list with the same toggle.
- **Antislop for the Word target.** A condensed writing rule set (about 3.5 KB) is added to the system prompt, so the AI avoids empty AI vocabulary, forced rhythm, filler, em dashes and invented facts.
- **Antislop for the VS Code target.** The skills `antislop`, `antislop-ui` and `antislop-code` are installed into `.snapgent/skills/` when you turn Antislop on. Existing files are never overwritten. The AI reads them when a task matches.
- **Dimmed rows.** For MCP targets other than Word and VS Code (for example Roblox Studio, REA and EffectCraft), the Antislop row is dimmed and cannot be toggled. Imported workspace skills are only active on VS Code.
- Antislop is **off by default**. Changes apply to the next chat session.

### Changed
- Extension and Snapgent App versions bumped to **3.9.11**.

### Upgrade
Reload the extension at `chrome://extensions` (or `edge://extensions`) and refresh open chat tabs (F5) so the popup shows `ext v3.9.11`. Open the Switch AI menu and look for the **Skills** section.

The attached zip contains everything needed to run: the extension, `bridge.exe`, `vscode_mcp.exe`, the start scripts (`start.bat`, `MacOS_Start.command`, `Linux_Start.sh`), the setup scripts, the Python sources and the README. Extract it, load the `snapgent-extension` folder, and run the start script for your system. The Word target needs `uv` installed (https://docs.astral.sh/uv/).
