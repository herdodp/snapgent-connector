## snapgentV3 V3.9.4

This release makes the bridge start faster and more reliably, and ships a rebuilt Windows `bridge.exe`.

### Changed
- **MCP servers now start in parallel.** The bridge used to start servers one by one, so a slow or failing server (for example Roblox Studio not ready yet) delayed all the others. Servers now start together with `asyncio.gather`, and a startup error in one server no longer affects the rest.
- **The WebSocket opens before the servers start.** The extension can connect immediately. The tool catalogue is rebuilt and broadcast as each server becomes ready, so tools appear one server at a time instead of all at once.
- Bridge version bumped to **3.9.4**.
- The release badge, install link and footer in `README.md` now point to V3.9.4.

### Fixed
- **`bridge.exe` could not find `config.json` or write logs when frozen.** In a PyInstaller build, `__file__` points to a temporary extraction folder. The bridge now uses the folder of the `.exe` as its root.
- **`bridge.exe` rebuilt.** The bundled Windows binary now includes the V3.9.2 large-response fix, the version display and parallel startup, so the popup no longer shows `bridge old` on Windows.

### Upgrade
Pull the latest `main`, close and restart `start.bat`, then reload the extension at `chrome://extensions` (or `edge://extensions`) and refresh open chat tabs (F5).
