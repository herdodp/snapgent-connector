The AI chat you already use, working inside VS Code.

snapgentV3 is a browser extension and a local bridge. Your chat sends plain-text commands, the bridge runs them on the workspace you have open, and the results go back into the conversation. No API key, no sign-in.

Download the latest release Watch the demo video (YouTube)
  • Free and open source, GPL-3.0
  • The bridge runs on your computer
  • Edge and Chrome, Manifest V3

One command at a time, checked by you in the chat.

The AI does not get a remote shell. It writes a command in its reply, and the extension runs that one command and pastes the result back.

  1. You

    Describe a task in a supported AI chat, in plain language.

  2. The AI

    Replies with a command, written as a small JSON block.

  3. Extension

    Detects the command and forwards it to the local bridge.

  4. Bridge

    Routes it to the VS Code MCP server for your open workspace.

  5. Chat

    Receives the result, and the AI continues from there.

This is what a command looks like in a reply:

{"command":"read_file","params":{"path":"README.md"}}

Where the tools say no.

These limits are built into the server, so they hold whatever the AI asks for.

delete_file
Deletes one file. Directories, the workspace root and anything under .git are refused.
apply_patch
Applies several exact replacements to one file. Each old_text must match exactly once, and nothing is written if any edit fails.
git_add
Stages the paths you name. Staging the whole workspace is refused.
git_commit
Commits what is already staged. It never stages files itself and has no amend option.
create_file, move_file, copy_file
Never overwrite an existing destination.
edit_file
Replaces an exact snippet, which must be unique unless replace_all is set.

From download to first command.

Needs Microsoft Edge or Google Chrome, and VS Code. On macOS and Linux the bridge also needs Python 3.9 or newer. Windows ships the bridge as an executable.

  1. Load the extension

    Download and extract the latest release. Open edge://extensions or chrome://extensions, turn on Developer mode, choose Load unpacked, and select the snapgent-extension folder.

  2. Open your project in VS Code

    Open the folder you want to work on. The bridge can start before VS Code. The agent waits until a workspace is open and never falls back to the release folder.

  3. Start the bridge

    Keep its window open while you work. Closing it disconnects the agent.

    Windows
    start.bat
    macOS
    MacOS_Start.command
    Linux
    bash Linux_Start.sh

    On macOS the first launch may show a Gatekeeper warning. Choose Done, then allow the script in System Settings, Privacy & Security.

  4. Start a session

    Open a supported AI site, start a new chat, click Start in the snapgentV3 bar above the input box, and describe what you want. The installation video walks through it (YouTube).

If something is off

The snapgentV3 bar is missing
Check that the extension is enabled and allowed on the current site, then reload the tab.
The bridge shows as offline
Start the launcher for your system and keep its window open.
The AI answers without using tools
Remind it to use snapgentV3 commands, or start a new chat.

Other targets, one click away.

VS Code is the default target. The MCP selector in the chat bar can also point the bridge at Roblox Studio or EffectCraft, and you can switch at any time. After a switch the page reloads, and a running session in that tab has to be started again.

EffectCraft support is optional and needs EffectCraft installed. Roblox Studio needs its built-in MCP server enabled. The README has the detection details for each system.
