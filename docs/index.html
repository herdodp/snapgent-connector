The AI chat you already use, connected to your apps.

snapgentV3 is a browser extension and a local bridge. Your chat sends plain-text commands, the bridge runs them on an MCP server for the app you chose, and the results go back into the conversation. No API key needed.

Download the latest release Watch the demo video (YouTube)
  • Free and open source, GPL-3.0
  • The bridge runs on your computer
  • Edge and Chrome, Manifest V3

One command at a time, visible to you in the chat.

The AI does not get a remote shell. It writes a command in its reply, and the extension runs that one command and pastes the result back.

  1. You

    Describe a task in a supported AI chat, in plain language.

  2. The AI

    Replies with a command, written as a small JSON block.

  3. Extension

    Detects the command and forwards it to the local bridge.

  4. Bridge

    Routes it to the MCP server of the target you selected.

  5. Chat

    Receives the result, and the AI continues from there.

This is what a command looks like in a reply:

{"command":"read_file","params":{"path":"README.md"}}

One chat, many targets.

Each target is an MCP server. Pick one in the selector in the chat bar and switch at any time. The AI only sees and can only use the target you selected.

VS Code default

  • Read and search files
  • Edit, create, move, copy
  • Git status, diff, add, commit
  • Run scripts and tests

Roblox Studio

  • Uses Studio's built-in MCP server
  • Read and edit scripts
  • Inspect the game tree

EffectCraft optional

  • Needs EffectCraft installed
  • Detected by the bridge

Other MCP servers

  • The bridge can run additional MCP servers
  • Each one stays isolated

Available commands depend on the target. Ask the AI to run list_commands to see exactly what the selected target offers.

Where it says no.

These limits are built in, so they hold whatever the AI asks for. The examples below are from the built-in VS Code server.

Target isolation
The AI can only list and use the MCP server you selected. Other servers, even enabled ones, stay invisible, and a disabled server cannot be used.
delete_file
Deletes one file. Directories, the workspace root and anything under .git are refused.
apply_patch
Applies several exact replacements to one file. Each old_text must match exactly once, and nothing is written if any edit fails.
git_add
Stages the paths you name. Staging the whole workspace is refused.
git_commit
Commits what is already staged. It never stages files itself and has no amend option.
create_file, move_file, copy_file
Never overwrite an existing destination.
edit_file
Replaces an exact snippet, which must be unique unless replace_all is set.

From download to first command.

Needs Microsoft Edge or Google Chrome, plus the app you want to control, such as VS Code or Roblox Studio. On macOS and Linux the bridge also needs Python 3.9 or newer. Windows ships the bridge as an executable.

  1. Load the extension

    Download and extract the latest release. Open edge://extensions or chrome://extensions, turn on Developer mode, choose Load unpacked, and select the snapgent-extension folder.

  2. Open your app

    Open the app you want to control. For the default VS Code target, open the folder you want to work on. The bridge can start before VS Code. The agent waits until a workspace is open and never falls back to the release folder. For Roblox Studio, open a place and enable its built-in MCP server.

  3. Start the bridge

    Keep its window open while you work. Closing it disconnects the agent.

    Windows
    start.bat
    macOS
    MacOS_Start.command
    Linux
    bash Linux_Start.sh

    On macOS the first launch may show a Gatekeeper warning. Choose Done, then allow the script in System Settings, Privacy & Security.

  4. Start a session

    Open a supported AI site, start a new chat, choose your target in the snapgentV3 bar above the input box, click Start, and describe what you want. The installation video walks through it (YouTube).

If something is off

The snapgentV3 bar is missing
Check that the extension is enabled and allowed on the current site, then reload the tab.
The bridge shows as offline
Start the launcher for your system and keep its window open.
The AI answers without using tools
Remind it to use snapgentV3 commands, or start a new chat.
The target does not respond
Check that the app is open and its MCP server is running, then switch the target in the selector. After a switch the page reloads, and a running session in that tab has to be started again.

The README has the detection details for each system.
