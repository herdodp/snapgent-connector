## snapgentV3 V3.9.13

Qwen Coder is now a separate supported provider, and fresh installations no longer select
an MCP target automatically.

### Added
- Qwen Coder support for `coder.qwen.ai`, separated from Qwen Chat's `chat.qwen.ai` provider.
- A **None** MCP target for fresh installations. No MCP tools are loaded or commands sent
  until the user selects a target. Existing saved target preferences are preserved.
- Qwen Coder's own composer, send-button and status-bar integration.

### Changed
- Extension and Snapgent App versions bumped to **3.9.13**. The bridge is unchanged
  (still 3.9.7), so `bridge.exe` does not need to be rebuilt.

### Upgrade
Reload the extension at `chrome://extensions` (or `edge://extensions`) and refresh open chat
tabs. Choose an MCP target from the snapgentV3 bar before starting an agent session.

The attached zip contains the extension, bridge, MCP server, setup scripts, manual app
launchers, Python sources and README. Extract it, load the `snapgent-extension` folder, and
run the start script for your system.

Full history: see [CHANGELOG.md](https://github.com/herdodp/snapgent-connector/blob/main/CHANGELOG.md).
