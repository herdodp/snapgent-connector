## snapgentV3 V3.9.14

This release includes the Firefox/VSCodium improvements from [PR #8](https://github.com/herdodp/snapgent-connector/pull/8)
and the ChatGPT composer, resume, replay-guard and live-status updates from
[PR #6](https://github.com/herdodp/snapgent-connector/pull/6).

### Added
- Firefox MV3 support, including a Gecko extension ID and corrected background startup.
- VSCodium and Code - OSS workspace detection on Linux, including Flatpak and Snap paths.
- IPv4 and IPv6 loopback listeners for the bridge.
- An opt-in Remote commands setting, command resume after reload, and a local live view
  for bridge tool progress.

### Fixed
- ChatGPT composer sends are checked against the requested message before sending. The
  comparison tolerates dropped paragraph separators but preserves spaces and tabs,
  including at the beginning and end of the message.
- ChatGPT's current turn layouts and assistant reply variants are read correctly.
- Replayed tool calls are deduplicated, and cancelled bridge calls no longer remain in the
  busy status.

### Changed
- Extension, Python bridge and Snapgent App status version are **3.9.14**.
- The bundled Windows `bridge.exe` is rebuilt from the updated bridge source and includes
  `aiohttp` for the live status view.

### Upgrade
Extract the release archive and reload the `snapgent-extension` folder in your browser.
Firefox users can load it temporarily from `about:debugging` > **This Firefox** >
**Load Temporary Add-on**. Run the included start script to start the bridge.

The archive includes the Windows bridge executable, Python bridge source, MCP server,
extension, setup scripts and platform launchers.
