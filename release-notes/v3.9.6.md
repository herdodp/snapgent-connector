## snapgentV3 V3.9.6

This release gives the extension UI a consistent yellow and black theme.

### Changed
- **Yellow / black theme for the UI.** Result chips (including the outer ChatGPT box), the Switch AI menu and the MCP servers popup now share one yellow on warm near-black palette, with matching light-mode variants. Success and error chip colours are unchanged.
- Extension and Snapgent App versions bumped to **3.9.6**. Reload the extension so the popup shows `ext v3.9.6`. The bridge is unchanged (still 3.9.4), so `bridge.exe` does not need to be rebuilt.
- The release badge, install link and footer in `README.md` now point to V3.9.6.

### Upgrade
Pull the latest `main`, reload the extension at `chrome://extensions` (or `edge://extensions`) and refresh open chat tabs (F5). The bridge does not need to be restarted for this release.

Full history: see [CHANGELOG.md](https://github.com/herdodp/snapgent-connector/blob/main/CHANGELOG.md).
