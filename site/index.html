START MAKING

Ready when you are.

Install the extension, enable Studio's built-in MCP server, then start the local bridge. You can be in your first session in minutes.

Get snapgentV3 V3 ↗
  1. 01
    Load the extension

    Unpack the release and load snapgent-extension in Edge or Chrome.

  2. 02
    Enable Studio MCP

    In Roblox Studio, turn on Enable Studio as MCP Server.

  3. 03
    Run the bridge

    Open start.bat on Windows or MacOS_Start.command on macOS.

OPTIONAL MCP TARGET

More than one workspace?

Connect a configured VS Code MCP server or another MCP tool from the target selector in the chat bar. Roblox Studio remains ready as the built-in target.
